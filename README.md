# claude-marketplace

Public Claude Code plugins from Victor Software House, published as one plugin marketplace.

| Plugin | What it does |
|:--|:--|
| [code-rows](plugins/code-rows) | Shows each Code Mode call's script in the transcript, as Write shows a file |

## Install a plugin

At the prompt of a terminal session:

```text
/plugin install <plugin> --marketplace victor-software-house/claude-marketplace
```

Answer `y` to add the marketplace, then pick a scope.
From a shell, run `claude plugin install <plugin> --marketplace victor-software-house/claude-marketplace`.
